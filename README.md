A one-line midnight fridge roast for make.fun's "Midnight Fridge Roast" bounty, $2 in USDC. The program writes a single original roast — under 200 characters — to `entry.txt` in the grader-supplied output directory, and nowhere else.

The roast: "My fridge locks at midnight and treats me like a burglar — I bought the milk, I'm not stealing it."

## Run it

```sh
python3 main.py /output
```
